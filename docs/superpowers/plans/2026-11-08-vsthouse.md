# VSTWorld Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar o aplicativo mínimo aprovado com fontes HTML configuráveis e limites explícitos do VSTHouse.
**Architecture:** Um servidor Python, interface estática, consultas ao vivo, links de download sem proxy. Configuração declarativa, sem banco.
**Tech Stack:** FastAPI, Uvicorn, HTTPX, BeautifulSoup, unittest, Docker Compose.
**Spec:** `docs/superpowers/specs/2026-11-08-vsthouse-design.md` (aprovado em conversa).

## Global Constraints

- Sem serviços SaaS, autenticação multiusuário, streaming ou cache avançado.
- Preservar query e paginação por fonte; respeitar robots e validar destinos públicos.
- Nenhuma alteração no EveryTune; nenhum Bend.
- VSTHouse restrito deve ser apresentado como restrito, sem alegação de busca operacional.

## Review Focus

1. DNS privado ou alterado: recusar e fixar IP público por conexão.
2. Redirect entre hosts: verificar allowlist e robots em cada salto.
3. HTML remoto malicioso: não executar nem inserir marcação remota.
4. Fonte falhando: manter resultados das demais; limitar tempo e tamanho.
5. Paginação/referência expirada: erro explícito, sem aceitar URL arbitrária na API.
